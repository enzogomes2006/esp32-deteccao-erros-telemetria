# Fonte LaTeX do relatório

O arquivo principal é `main.tex`. Ele contém o relatório acadêmico, a capa com os dados informados, o resumo, o sumário automático, as equações, as tabelas e o apêndice de registros.

Para editar, abra este projeto em um editor LaTeX e compile `main.tex`. Os pacotes utilizados são comuns às distribuições LaTeX. São necessárias duas passagens para atualizar o sumário; ferramentas que gerenciam a compilação automaticamente fazem isso por conta própria.

O PDF de entrega fica um nível acima, em `Relatorio_Final_ESP32.pdf`. O guia operacional da demonstração é separado do relatório. Alterações de tipografia e numeração não alteram os CSVs nem os programas das placas.
